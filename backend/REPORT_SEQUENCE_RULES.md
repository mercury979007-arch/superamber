# 日报任务排序规则

这份规则文档只描述“完成公示/日报导出里的任务排序”，故意和抓取、工作簿生成、页面入口解耦。

## 目标

- 主任务之间保持分组，不拍平。
- 每个主任务内部只走一套规则。
- 把“步骤型”和“常规型”拆开，后续修改时只改这一层。

## 规则一：步骤型

判定：

- 主任务块内出现 `步骤1 / 步骤2 / ...`

排序：

- 只按步骤号排序。
- 相同步骤号时保留原始顺序。

示例：

- `步骤1 -> 步骤2 -> 步骤3 -> 步骤4`

## 规则二：常规型

判定：

- 主任务块内没有明确 `步骤N`

### 2.1 有 Lesson / L

判定：

- 标题或主任务标题包含 `Lesson 8`、`L8` 这类明确课次标记

排序：

1. 先按课次第一次出现的顺序排
2. 同课次内部按语义排：
   - `测试`
   - `课前 / 预习 / 新知`
   - 裸 `Lesson/L` 资源
   - `课后 / 温故 / 回顾 / 句型表达`
   - `小挑战`
3. `AI语音` 跟普通内容同语义层时，放在普通内容后面

补充：

- 如果课次出现 `7 -> 8 -> 1`，则视为跨单元延续，保持首次出现顺序，不把 `1` 提前插回最前面。

### 2.2 没有 Lesson / L，但有时间语义

判定：

- 没有 `Lesson/L`
- 但有 `周中 / 周末 / 下周周中`

排序：

1. `周中`
2. `周末`
3. `下周周中`

同一时间桶内部保留原始顺序。

## 主任务边界

- 排序永远先按 `groupOrder`
- 再排主任务内部内容
- 不能把两个主任务先拍平再统一排序

- `J413`：常规型
