# Repository map

- `frontend/`: React and Vite application, including seating and report tools.
- `backend/`: Express API, business logic, and tests.
- `config/`: non-secret example configuration and calendar rules.
- `scripts/`: release guards and deployment workflow requiring local configuration.
- `tools/`: optional data preparation utilities.
- `third_party/smiley-sans/`: font license notice.

Private data and runtime files are intentionally absent.
